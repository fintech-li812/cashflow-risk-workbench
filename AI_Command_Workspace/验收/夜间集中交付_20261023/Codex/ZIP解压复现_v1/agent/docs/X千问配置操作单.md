## 一、身份与版本字段表（五个必填，一次配好）

这五个字段在所有环节必须一致，缺一不可。来源只能是平台认证绑定，**不能从文件名或公司名称推断**。

| 字段名 | 类型 | 填什么 | 由谁提供 |
|---|---|---|---|
| `tenant_id` | 非空字符串 | 租户标识 | 平台认证绑定自动带入 |
| `company_id` | 非空字符串 | 企业标识 | 平台认证绑定自动带入 |
| `period` | 非空字符串 | 期间，`YYYY-MM`，月份须合法（如 `2026-08`） | 本次请求指定 |
| `source_revision` | 非空字符串 | 源数据版本号；**源数据一变必须换新值** | 导入/取数包生成 |
| `run_id` | 非空字符串 | 本次运行标识，每次运行一个新值 | 运行时生成 |

保存环节额外一个字段：`request_id`（每次逻辑保存的非空标识，与 `run_id` 不同；重试沿用同一个值）。

成功证据：在 Agent 里问“当前 tenant/company/period/source_revision/run_id 分别是多少”，能逐项答出且与表格一致。

## 二、配置步骤（逐步做，每步留证据）

### 步骤 1 · 绑定数据源（read_snapshot）

- 位置：Agent 配置 → 数据源 / 表格绑定
- 动作：选择制造业工作簿，指定本次使用的 Sheet 与取数区域
- 必填配置项名：`workbook_ref`、`sheet`、`range`、`snapshot_ref`
- 成功证据：Agent 能返回这四个值，且 `snapshot_ref` 不是空字符串
- 未达成：回报“read_snapshot 未绑定”，**不要手工把数字填进 Agent 回答里**

### 步骤 2 · 绑定计算公式（read_calculated_result）

- 位置：千问表格 → 已批准现金流公式
- 动作：确认公式可计算出流入 / 流出 / 净额 / 期末
- 必填配置项名：`calculation_version`（公式版本号，非空）
- 成功证据：改一个输入单元格后重算，结果随之变化，且能报出 `calculation_version`
- 未达成：回报“算法未就绪”，结果状态记为 unavailable，**不给出任何金额**

### 步骤 3 · 绑定保存工具（save_result）

- 位置：Agent 配置 → 工具 / MCP 连接
- 动作：查看该工具的 **`tools/list` 返回的真实 `inputSchema`**，把字段名抄录下来
- 必填配置项名：由实际 `inputSchema.required` 决定（**待平台确认，我方未提供预设名**）
- 成功证据：能列出该工具真实必填字段清单，并截图或抄录
- 未达成：回报“存储工具未绑定”，**不要凭提示词里的字段名提交**

### 步骤 4 · 绑定回查能力（query_saved_result）

- 位置：同上工具配置
- 动作：确认能否**按 `request_id` 精确查询**已保存记录
- 成功证据：用一个刚保存的 `request_id` 回查，能取到同一条记录及 `payload_sha256`
- 不支持：回报“无精确回查能力”，我方会给出只读人工核对步骤，**不要靠猜或者看最新一条代替**

### 步骤 5 · 粘贴提示词

- 位置：Agent 配置 → 系统提示词
- 动作：把 `agent/制造业现金流主提示词_v3.txt` 全文粘贴
- 成功证据：Agent 首次回复能主动报出企业、期间、来源版本，而不是直接给金额

### 步骤 6 · 加载追问

- 位置：Agent 配置 → 追问 / 常用话术（若无可跳过）
- 动作：把 `agent/八条制造业现金流追问_v3.md` 八条加入
- 成功证据：问“为什么是黄灯/差异多少”，Agent 按第 5 或第 8 条格式回答，并带出真实数值
