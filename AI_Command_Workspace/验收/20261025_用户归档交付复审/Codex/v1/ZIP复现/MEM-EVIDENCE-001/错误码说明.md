# 错误码与退出码说明

版本：MEM-EVIDENCE-001 v1。本文件描述 **CLI 进程退出码** 与 **JSON 返回体中的 code/status** 两套口径，二者一一对应。

## 1. 退出码表

| 退出码 | code | 含义 | 是否表示成功 | 典型场景 |
|---|---|---|---|---|
| 0 | OK | 操作完成 | 是 | save 创建/回放成功、get/history/verify-store 通过、selftest 全通过 |
| 1 | INTERNAL_ERROR | 未预期内部异常 | 否（绝不伪装成功） | 未捕获异常，打印原文 traceback |
| 2 | USAGE | 用法错误 / 路径越界 | 否 | store 路径逃出 workdir、非法后缀、workdir 不存在或非空、缺参数 |
| 3 | VALIDATION_FAILED | 结果校验拒绝 | 否 | 金额非法/非有限值、缺必填、身份或源版本不匹配、非 success、默认拒 fixture |
| 4 | CONFLICT | 幂等键冲突 | 否 | 同 (tenant,company,operation,request_id) 但 payload 摘要不同，拒绝覆盖 |
| 5 | NOT_FOUND | 身份范围内无此记录 | 否 | get 的 record_id 在本身份范围内不存在 |
| 6 | SCOPE_DENIED | 越权/身份范围不符 | 否 | 用他身份上下文读取、CLI 自填身份与可信上下文不一致 |
| 7 | STORAGE_BUSY | 存储锁等待超时 | 否（不无限重试） | SQLite busy_timeout=3000ms 到点仍拿不到写锁 |
| 8 | VERIFY_FAILED | 一致性复核失败 | 否 | 摘要不匹配、关联身份被改、回执字段缺失、金额勾稽失败 |
| 9 | FAULT_INJECTED | 故障注入子进程终止 | 否（仅测试入口） | --fault-before-commit / --fault-after-commit |
| 10 | SELFTEST_FAILED | 自测存在失败/阻塞/未执行 | 否 | 断言不匹配、依赖缺失 |
| 11 | UNKNOWN_STATE | 保存状态未确定 | 否（**不等于成功**） | 提交已完成但回执未能确定交付 |

## 2. 返回体结构

成功：`{"ok":true,"code":"OK","status":"committed","outcome":"created|replay|diagnostic","receipt":{...},...}`
失败：`{"ok":false,"code":"<上表 code>","status":"<语义状态>","message":"...","details":{...}}`

回执（`receipt`）字段遵循 mfg-evidence.v1：schema_version / kind=receipt / operation / 五字段 /
request_id / record_id / payload_sha256 / stored_at / status=committed，另附 `is_fixture`、
`reconciliation_state` 与 `note`（本地存储 ID，不是 MySQL 主键）。

## 3. 语义状态（与业务 status 分开）

| status | 说明 |
|---|---|
| committed | 本地 SQLite 事务已提交；**不表示**服务端 MySQL 已入库 |
| conflict | 同幂等键不同载荷，拒绝覆盖 |
| denied | 越权或身份范围不符，响应不含他家记录内容 |
| not_found | 范围内不存在该 record_id |
| busy | 锁等待超时，未写入 |
| tampered | 一致性复核检出问题 |
| unknown | 提交结果未确定，不得改称已保存 |
| blocked | 明确的业务缺项（如非 success 走诊断通道）；与测试状态通过/失败分开 |

测试结果状态只有四个：通过 / 失败 / 阻塞 / 未执行，与业务 status 互不相干。

## 4. 重试与恢复语义

- 出现 7（锁超时）：不做重试循环，调用方按统一规则等待后自行重试，并沿用同一 request_id。
- 出现 11（未确定）：先用同一 request_id 精确回查；命中则返回原 record_id（退出码 0），不得换 ID 重提。
- 出现 4（冲突）：必须用新的逻辑 request_id，旧记录保留不覆盖。
- 退出码 1/2/3 属于明确失败，不需要重试同一输入。
