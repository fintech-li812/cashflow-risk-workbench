# 错误码与 issue_code 说明

> `issue_code` 是**导入问题分类**，不是 gate_ 规则、不是数据闸结果、不是风险灯、不是数据库 event_type。

## 1. issue_code（写入 issues.jsonl / issues.csv / report.html）

| 代码 | 含义 | 触发条件 | 建议人工动作 |
|---|---|---|---|
| `MISSING_SHEET` | 缺必需 Sheet | 映射要求但该工作簿没有 | 补齐源文件或更新映射 |
| `MISSING_COLUMN` | 缺必需列 | 表头与别名均无匹配 | 补齐列或更新映射别名 |
| `MISSING_FIELD` | 纵向表缺必需字段 | 字段名无匹配 | 补齐字段或更新映射 |
| `DUPLICATE_COLUMN` | 重名列 | 同一字段名命中多列（同名） | 人工消除歧义，不取第一项 |
| `DUPLICATE_FIELD` | 纵向表重名字段 | 同一字段名命中多行 | 人工消除歧义 |
| `ALIAS_AMBIGUITY` | 别名歧义 | 同一字段的两个不同别名同时出现 | 确定主别名后重导 |
| `UNIT_SUSPECT_PENDING` | 已登记单位疑点 | 源SHA+Sheet+地址同时匹配例外 | 核实真实单位后按批准口径重导（不自动换算） |
| `UNIT_UNKNOWN` | 单位未批准 | 映射声明的单位不在已知集合 | 确认单位并更新映射 |
| `DUPLICATE_ROW` | 重复行 | 同表内两行原始取值完全相同 | 保留并人工确认是否重复录入（不自动删） |
| `INVALID_AMOUNT` | 非法金额 | 金额单元格为非数字文本或不可解析 | 人工核对源单元格 |
| `NON_FINITE_AMOUNT` | 非有限金额 | NaN / Infinity 之类 | 修正源数据 |
| `NUMERIC_TEXT_NOT_CONVERTED` | 数字文本未转 | 金额列是文本型数字 | 确认是否按数值处理（未批准不偷转） |
| `INVALID_DATE` | 非法日期 | 序列越界/含小数，或文本非真日历日期（2026-13-05、2026-02-30） | 人工核对源日期，**不自动进位** |
| `INVALID_DATE_FORMAT` | 日期格式未声明 | 文本日期不符映射声明的格式 | 在映射中声明格式后重导 |
| `TWO_DIGIT_YEAR` | 两位年份 | 如 `26-01-31` | 补全四位年份，不猜世纪 |
| `EXCEL1900_FICTITIOUS_LEAP_DAY` | Excel1900 虚构闰日 | 1900 系统 serial=60 | 说明是虚构闰日，值 null，不作为业务日期 |
| `INVALID_MONTH` | 非法月份 | `YYYY-MM` 月份不在 1–12 | 人工核对 |
| `FORMULA_CACHE_MISSING` | 公式缓存缺失 | 有 `<f>` 无 `<v>` | 在源系统重算导出或改固定值；**本工具不 eval 代算** |

## 2. 字段取值状态（normalized.transform.status，值为 null 时的原因）

| status | 含义 |
|---|---|
| `missing_cell` | 该地址单元格不存在 |
| `blank_cell` | 单元格元素存在但无值 |
| `empty_string` | 显式空字符串 |
| `whitespace_only` | 仅空格/制表符 |
| `numeric_text_not_converted` | 文本型数字，未经批准不转 |
| `formula_cache_missing` | 公式缓存缺失 |
| `unit_suspect_pending` | 命中登记的单位疑点 |
| `unit_unknown` | 单位未批准 |
| `invalid` / 具体错误码 | 非法值，不静默修正 |

## 3. 进程退出码

| 退出码 | 场景 |
|---|---|
| 0 | scan 技术执行成功 / verify 全部通过 / selftest 全 PASS |
| 1 | verify 存在不符项；运行期意外异常（含 selftest 用例意外异常） |
| 2 | 参数或环境错误：输出目录已存在、period 非法、身份字段缺失、包/源目录不存在、缺必需参数 |

程序异常不得伪装成 BLOCKED；意外异常一律打印 `[意外错误]` 并返回非 0。
