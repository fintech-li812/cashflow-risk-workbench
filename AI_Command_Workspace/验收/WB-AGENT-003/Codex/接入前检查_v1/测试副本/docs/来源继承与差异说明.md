## 三、相对继承包的变化（逐条）

1. **新增“未绑定”的一等公民表达**：继承包只有 `unavailable(context)` 一个结果级函数，
   不区分是读表未绑定、算法未绑定还是存储未绑定。本包把 unavailable 拆到四个能力上，
   各带自己的缺项清单与人工取证步骤。
2. **新增源版本失效重取**：继承包不处理缓存。本包 `RequestFlow` 以 `(tenant, company, period)`
   为键缓存结果并记录 `source_revision`，版本一变即失效重取（测试 `test_04` 覆盖）。
3. **新增保存侧语义**：继承包明确说明“当前代码不实现保存工具”。本包补齐幂等键、
   超时 pending、同键冲突、跨租户隔离、无回查能力时的只读核对步骤。
4. **新增守卫前置检查**：继承包的 `validate_result` 只在 `status == success` 时校验金额。
   本包的 `pre_guard_amounts` 先检查缺字段、非字符串、非有限数，让失败原因更具体；
   勾稽与格式判定仍完全交给继承的 `agent_guard`，**不重复造规则**。
5. **提示词 v3**：只增补四类能力顺序、超时沿用同一 ID、冲突不覆盖、部分口径说明；
   其余口径原样沿用 v2。
6. **未改动判定规则**：金额正则、勾稽等式、origin 生产限制、coverage 判定等，
   全部来自继承的 `agent_guard.py`，本包未复制粘贴改写。
