## 四、结果/回执字段（mfg-agent-result.v1 / mfg-evidence.v1）

`mfg-agent-result.v1` 状态闭集：`success / missing_inputs / formula_error / unavailable`；**非 success 时 amounts=null**。成功结构要求 `full_cashflow`，不能把仅经营样例伪成 full_cashflow；经营部分视图未批准就列"接口待确认"，不私加 status 或 coverage。

`amounts` 七键：`opening / inflow / outflow / net / closing / actual_closing / difference`。独立实际余额缺失时 `actual_closing` 与 `difference` 均 null，不能假报完成勾稽。金额为元 CNY 两位小数列串或规则允许 null；源万元保留原精度 ×10000 后 ROUND_HALF_UP 落分，单位疑点不换算。

`mfg-import.v1` 与 `mfg-evidence.v1` 按统一接口抄准，**不作为现有 MCP/SQL 字段直接上线**。
