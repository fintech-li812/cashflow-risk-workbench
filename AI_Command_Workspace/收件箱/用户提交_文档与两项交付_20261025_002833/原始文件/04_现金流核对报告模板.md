# 04 现金流核对报告模板（MEM-DOC-001 候选）

> 任务号：MEM-DOC-001｜作者：包A（团队角色）/ WorkBuddy（AI）｜版本：v1｜候选状态：待 Codex 确认
> 适用范围：**仅制造业实际现金流一期**。其他行业、评级、K灯级、FUSE 等暂停，不出现。
> 用法：复制本模板填写；**不补 0、不自动调平、不把应收/折旧/未用授信当现金**。缺独立余额时实际余额与差异标"未提供"，明确勾稽未完成。

## 一、报告必含要素（每项都要填）

- 企业 / 期间 / 范围 / 版本 / 来源
- 实际流入 / 流出 / 净额 / 期初 / 计算期末 / 独立实际期末 / 差异
- 单位（元 CNY，或明确源万元）
- 分类覆盖（经营 / 投资 / 筹资，逐项列有无）
- 缺项清单
- 证据索引（相对路径 + 定位 + 源哈希 + 观察者）
- 下一步负责人

## 二、统一公式（一期范围 v1）

```
净现金流   = 现金流入合计 − 现金流出合计
期末现金   = 期初现金 + 本期净现金流
下一期期初 = 上一期已核对的期末现金
勾稽差异   = 独立实际期末余额 − 计算期末余额   （差异≠0 列明证据与待核，不自动补平）
```
