# CMD-002 独立审核与返工流程 v1
用户指定DeepSeek Harness为主力审核员，即刻适用于后续代码交付。
WorkBuddy为主力开发，Codex发布任务标准并确认最终验收；DeepSeek独立审核所有成员与AI代码，输出明确打回原因、修改建议和复验条件；千问保留平台调试。
顺序：开发完成并暂停 → Codex冻结候选 → DeepSeek审核 → Codex确认打回/放行 → 原作者返工 → DeepSeek复核 → Codex最终确认。
全部串行。不得同时开发和审核同一或其他任务，不覆盖历史交付，DeepSeek不修改被审代码，不自审自产代码。
每个项目先有专项标准。当前财务风控六个代码包标准已发布在规则/财务风控项目_代码审核标准_v1.md；通用标准在规则/代码审核通用标准_v1.md。
001开发完成后优先进入DS-AUD-001，审核通过且Codex确认前不得启动WB-ENG-002。002至006各自在交付后插入对应独立审核，具体审核任务由Codex逐包发布。
此前DS-RULE-001保留排队；不因审核角色调整自动开工。
