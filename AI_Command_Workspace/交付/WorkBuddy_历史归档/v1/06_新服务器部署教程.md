# 全新部署到新服务器 · 完整教程

适用场景：**换了一台新电脑 + 一台新阿里云 ECS**，要重建整套「竞赛小助手」网站（232 条竞赛 + 评级/种类/状态筛选）+ 本地「班级事务后台」自动同步到网站。

> 本文档里的真实配置模板取自当前运行中的服务器（`39.104.201.10`）。**令牌、IP、域名均用占位符 `<...>` 表示，部署时需替换成你自己的值。**

---

## 0. 先看架构（3 个角色）

| 角色 | 是什么 | 跑什么 |
|------|--------|--------|
| **新电脑（你操作）** | 你的 Windows 桌面 | 网站源文件 `index.html`、本地后台 `ClassBackend`（Node，端口 3000） |
| **新 ECS（阿里云）** | Ubuntu 24.04 云服务器 | nginx（托管网站）+ 同步接口 `api.py`（端口 4010） |
| **域名** | 如 `jdjrkj.online` | DNS 的 A 记录指向新 ECS 公网 IP |

数据流：
```
新电脑改 index.html ──scp──▶ 新ECS /var/www/html/index.html ──▶ 访客访问 https://域名
新电脑 ClassBackend 加事务 ──HTTPS POST──▶ 新ECS /api/site/affairs ──▶ 网站"班级通知"读取展示
```

## 2. 新电脑客户端环境

1. **SSH 客户端**：Windows 10/11 自带 OpenSSH（设置 → 可选功能 → 添加 OpenSSH 客户端）。或装 **Git for Windows**（后面 `sync_site.bat` 需要它的 `scp.exe`）。
2. **Node.js（22+）**：本地 `ClassBackend` 用到内置 `node:sqlite`，需要 Node 22+。
   - 推荐装官方 **Node.js 22 LTS**（https://nodejs.org），安装时勾选「Add to PATH」。
   - 或沿用 WorkBuddy 自带的 managed node，记下新电脑上它的路径（后面改 `.bat` 用）。
3. （可选）装 WorkBuddy + 把 `harness-anything` 技能目录放回 `C:\Users\<你>\.workbuddy\skills\`。

## 3. 阿里云：买 / 初始化新 ECS

1. 买一台 ECS，镜像选 **Ubuntu 24.04 LTS**。
2. 记下新公网 IP = `<NEW_SERVER_IP>`。
3. **安全组**（网络与安全 → 安全组 → 配置规则 → 入方向）：
   - `22` TCP，源 `0.0.0.0/0`（SSH，建议限你自己的 IP 更稳）
   - `80` TCP，源 `0.0.0.0/0`
   - `443` TCP，源 `0.0.0.0/0`
4. 登录方式：设置 root 密码，或保持密钥（推荐密钥，见第 4 步）。

## 4. 生成新 SSH 密钥 + 登录

在新电脑的 **Git Bash / PowerShell** 里：

```bash
# 生成密钥对（一路回车，不要设密码短语）
ssh-keygen -t ed25519 -f ~/deploy_keys/site_ed25519 -N ""

# 打印公钥，复制整行
cat ~/deploy_keys/site_ed25519.pub
```

把公钥注入新服务器（阿里云控制台 → 实例 → 远程连接 → **云助手** → 发送命令，或先用控制台 VNC/密码登录后执行）：

```bash
mkdir -p /root/.ssh && chmod 700 /root/.ssh
echo "ssh-ed25519 AAAA...这里粘贴你刚才复制的公钥整行..." >> /root/.ssh/authorized_keys
chmod 600 /root/.ssh/authorized_keys
```

测试免密登录（把私钥路径和 IP 换成你的）：

```bash
ssh -i ~/deploy_keys/site_ed25519 root@<NEW_SERVER_IP>
```

能进命令行就对了。

```bash

```

## 6. 域名 + HTTPS

**两种域名方案：**

- **方案 A：沿用 `jdjrkj.online`** —— 阿里云 DNS 把 `@` 的 A 记录改成 `<NEW_SERVER_IP>`；**旧 ECS 必须先停机/释放**，否则同一个域名指向两个 IP 会冲突。
- **方案 B：用全新域名** —— 注册新域名、提交实名认证、加 A 记录 `@ → <NEW_SERVER_IP>`。旧服务器/旧域名可保留作备份。

等 DNS 全球生效（用 `nslookup <域名> 8.8.8.8` 看到新 IP 即可，通常几分钟到几十分钟，实名后可能延迟更久）。

装 certbot 并申请证书（自动改 nginx 加 443 + HTTP→HTTPS 跳转 + 续期）：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d <域名>        # 按提示填邮箱，同意条款
certbot renew --dry-run           # 验证自动续期能用
```

> certbot 会生成/修改 nginx 站点配置。第 7 步我们会用自定义配置覆盖它（加入同步接口反代），所以这里跑通拿到证书即可。

## 7. 同步接口部署（班级事务后台 → 网站）

### 7.0 生成新令牌（重要，旧令牌作废）

```bash
python3 -c "import secrets;print(secrets.token_hex(24))"
# 得到一串 48 位十六进制，记为 <AFFAIRS_TOKEN>
```

下面 systemd 和本地 `sync.config.json` 都要用**同一个** `<AFFAIRS_TOKEN>`。

### 7.1 同步接口 `api.py`

保存到 `/opt/affairs/api.py`（代码本身不含令牌，从环境变量读取，无需改代码）：

```python
#!/usr/bin/env python3
import json, os, threading, datetime
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

DATA_FILE = '/var/www/data/affairs.json'
TOKEN = os.environ.get('AFFAIRS_TOKEN', '')
PORT = 4010
ALLOW = '*'

_lock = threading.Lock()

def _read():
    try:
        with open(DATA_FILE, 'r', encoding='utf-8') as f:
            return json.load(f)
    except Exception:
        return []

def _write(data):
    os.makedirs(os.path.dirname(DATA_FILE), exist_ok=True)
    tmp = DATA_FILE + '.tmp'
    with open(tmp, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    os.replace(tmp, DATA_FILE)

def _sanitize(affairs):
    out = []
    for a in affairs:
        if not isinstance(a, dict):
            continue
        out.append({
            'id': a.get('id'),
            'title': str(a.get('title', '') or ''),
            'category': str(a.get('category', '') or '其他'),
            'deadline': a.get('deadline') or None,
            'owner': a.get('owner') or None,
            'content': a.get('content') or None,
            'done': bool(a.get('done', False)),
            'created_at': a.get('created_at') or datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S'),
        })
    return out

class Handler(BaseHTTPRequestHandler):
    server_version = 'AffairsSync/1.0'
    def _cors(self):
        self.send_header('Access-Control-Allow-Origin', ALLOW)
        self.send_header('Access-Control-Allow-Methods', 'GET, POST, OPTIONS')
        self.send_header('Access-Control-Allow-Headers', 'Content-Type, x-admin-token')
    def _send(self, code, obj):
        body = json.dumps(obj, ensure_ascii=False).encode('utf-8')
        self.send_response(code)
        self.send_header('Content-Type', 'application/json; charset=utf-8')
        self.send_header('Content-Length', str(len(body)))
        self._cors()
        self.end_headers()
        self.wfile.write(body)
    def do_OPTIONS(self):
        self.send_response(204); self._cors(); self.end_headers()
    def do_GET(self):
        p = self.path.split('?')[0]
        if p == '/api/site/affairs':
            self._send(200, {'affairs': _read(), 'updated_at': datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S')})
        elif p == '/api/site/health':
            self._send(200, {'ok': True})
        else:
            self._send(404, {'error': 'not found'})
    def do_POST(self):
        p = self.path.split('?')[0]
        if p != '/api/site/affairs':
            self._send(404, {'error': 'not found'}); return
        if (self.headers.get('x-admin-token') or '') != TOKEN:
            self._send(403, {'error': 'forbidden'}); return
        try:
            n = int(self.headers.get('Content-Length', 0) or 0)
            raw = self.rfile.read(n) if n else b'{}'
            payload = json.loads(raw.decode('utf-8') or '{}')
            affairs = _sanitize(payload.get('affairs', []) if isinstance(payload, dict) else [])
            with _lock:
                _write(affairs)
            self._send(200, {'ok': True, 'count': len(affairs)})
        except Exception as e:
            self._send(400, {'error': str(e)})
    def log_message(self, *a):
        pass

if __name__ == '__main__':
    _write(_read())
    ThreadingHTTPServer(('127.0.0.1', PORT), Handler).serve_forever()
```

### 7.2 systemd 守护服务

保存到 `/etc/systemd/system/affairs-api.service`（**把 `<AFFAIRS_TOKEN>` 换成 7.0 生成的真实令牌**）：

```ini
[Unit]
Description=Class Affairs Sync API
After=network.target

[Service]
Environment="AFFAIRS_TOKEN=<AFFAIRS_TOKEN>"
WorkingDirectory=/opt/affairs
ExecStart=/usr/bin/python3 /opt/affairs/api.py
Restart=always
RestartSec=3
User=www-data
Group=www-data

[Install]
WantedBy=multi-user.target
```

### 7.3 nginx 站点配置（⚠️ 关键坑）

> **教训**：`/etc/nginx/sites-enabled/` 下的站点是**独立文件**，不是指向 `sites-available/` 的符号链接。改 `sites-available/` 那份**不会生效**，必须直接写 `sites-enabled/` 这份。

保存到 `/etc/nginx/sites-enabled/<域名>`（**`<域名>` 换成你的，证书路径 certbot 已生成好**）：

```nginx
server {
    server_name <域名>;

    root /var/www/html;
    index index.html;

    location /api/site/ {
        proxy_pass http://127.0.0.1:4010;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location / {
        try_files $uri $uri/ =404;
    }

    listen [::]:443 ssl ipv6only=on;
    listen 443 ssl;
    ssl_certificate /etc/letsencrypt/live/<域名>/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/<域名>/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
}
server {
    if ($host = <域名>) {
        return 301 https://$host$request_uri;
    }
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name <域名>;
    return 404;
}
```

### 7.4 启动并自检

```bash
systemctl daemon-reload
systemctl enable --now affairs-api
nginx -t && systemctl reload nginx

# 健康检查（本机）
curl -s http://127.0.0.1:4010/api/site/health          # 应 {"ok":true}
# 公网读取（应返回空列表）
curl -s https://<域名>/api/site/affairs                 # {"affairs":[]}
# 无令牌写入应被拒（403）
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://<域名>/api/site/affairs -H "Content-Type: application/json" -d '{"affairs":[]}'
```

## 12. 关键参数速查 + 故障排查

| 项 | 值 / 命令 |
|----|-----------|
| 生成令牌 | `python3 -c "import secrets;print(secrets.token_hex(24))"` |
| 网站根目录 | `/var/www/html` |
| 同步接口源码 | `/opt/affairs/api.py` |
| 同步接口服务 | `systemctl status/restart affairs-api` |
| 接口数据落盘 | `/var/www/data/affairs.json` |
| nginx 站点（生效文件） | `/etc/nginx/sites-enabled/<域名>`（独立文件，非符号链接！） |
| 本地后台端口 | `127.0.0.1:3000`（仅本机） |
| 同步接口端口 | `127.0.0.1:4010`（仅本机，经 nginx 反代出去） |

**常见坑：**
- **网站「班级通知」不更新** → 多半 `affairs-api` 服务停了：`systemctl restart affairs-api`。
- **nginx 反代不生效** → 确认改的是 `sites-enabled/` 那份且执行了 `nginx -t && systemctl reload nginx`。
- **本地后台「拒绝连接」** → 没先双击 `启动班级事务后台.bat`（3000 端口没进程监听）；或浏览器走代理拦截 `127.0.0.1`，把 `127.0.0.1;localhost` 加进代理「不使用代理」例外。
- **证书申请失败 (NXDOMAIN)** → DNS 还没生效或没加 A 记录，等几分钟/确认解析。
- **scp 上传失败** → 检查私钥路径、服务器是否开机、安全组 22 是否开放。
