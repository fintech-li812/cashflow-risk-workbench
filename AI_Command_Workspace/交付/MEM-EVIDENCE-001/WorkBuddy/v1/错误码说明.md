# 错误码说明（MEM-EVIDENCE-001 候选 v1）

CLI 退出码（stdout 始终为机器可读 JSON，含 status 字段）：

| 退出码 | status | 含义 | 典型场景 |
|---|---|---|---|
| 0 | committed / ok / PASSED | 成功：新提交、幂等回放、查询命中、verify 通过、selftest 全过 | TC-01/02/03/04/11b/12/16(retry)/18/19/22/24 |
| 1 | internal_error / FAILED | 非预期内部错误或测试断言失败 | TC-25（selftest 注入失败演示） |
| 2 | conflict | 同键异参冲突，旧记录未覆盖 | TC-13/17b |
| 3 | not_found | 记录不存在或不属于指定身份（两者不区分，防泄露） | TC-14 |
| 4 | invalid | 输入校验失败：金额格式/勾稽/必填/身份/源版本/fixture 未允许/路径越界 | TC-05/06/07/08/09/11a/23 |
| 5 | store_error | 存储层错误：锁超时（busy_timeout 用尽）、IO 失败、commit 前故障注入；明确返回，不无限重试 | TC-15 |
| 6 | tampered | verify-store 或读时复核检出哈希/关联/勾稽不一致 | TC-20/21 |
| 7 | diagnosed | 结果非 success：仅入诊断表，不产生正式保存回执 | TC-10 |
| 42 | （子进程裸退出，无 JSON） | 故障注入 after_commit：已提交但回执未返回即崩溃（仅测试子进程） | TC-16 首轮 |

约定：
- 不确定状态（锁超时/故障）如实返回非 0 与脱敏原因，**不冒充成功、不伪装 BLOCKED**。
- 测试四状态（PASS/FAIL/BLOCKED/未执行）只在 tests/run_tests.py 汇总中使用，与上述业务退出码分开，不混用。
- 越权、冲突、未确定与成功分开：越权→3，冲突→2，未确定→5，成功→0。
