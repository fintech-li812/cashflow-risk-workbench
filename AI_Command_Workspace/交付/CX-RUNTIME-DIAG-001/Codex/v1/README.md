# 本机MCP启动只读诊断

CX-RUNTIME-DIAG-001，Codex v1，2026-10-25。此工具检查现有制造业隔离联调入口，补运行诊断，不属于导入/导出/原生适配/发布总检四个外包任务。

已实现：绑定7个入口/源码/依赖/fixture摘要，验证APPROVED_SHA256与隔离库命名和端口，检查制造业原样例摘要，核对全部锁定依赖版本。
依赖探测子进程使用-I并清除CF_*及PYTHONPATH继承，不读取或打印密码。默认不探测网络；显式--probe-tunnel仅检查127.0.0.1 TCP连通，不能证明MySQL认证或表可用。
只读现有文件和分发元数据，报告写到调用者指定的新文件；不启动服务器、不恢复SSH、不监听端口、不停止进程、不建表、不写库、不修改千问连接器或样例。

运行（在本目录；输出必须不存在）：
```text
python -B doctor.py --output <全新报告.json>
python -B doctor.py --probe-tunnel --output <另一全新报告.json>
python -B -m unittest discover -s tests -v
```
退出0=本次所选检查通过；2=配置/完整性/依赖错配或报告不可写；3=运行环境或转发阻塞。默认报告的TCP为not_run，不能当作连通。

binding.json绑定本机明确候选路径，跨机器需由操作者另存新binding，保留本文件。不能为了绕过摘要错配自动更新摘要；源码有批准修订后才重建绑定。
源码候选不是生产批准。工具检查通过不表示真实千问原生表格、算法、MySQL认证或端到端完成。
