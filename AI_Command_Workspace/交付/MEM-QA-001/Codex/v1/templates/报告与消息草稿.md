# 制造业现金流报告模板（只形成草稿）

企业/期间/统计账户范围：待填写；数据性质：样例/合成/真实；来源版本/run/公式版本：待证据。
单位：元。实际流入、流出、净额、期初、计算期末、独立实际期末、差异分别引用真实结果。未知项写未提供，不填0。
口径覆盖：经营部分/完整经营投资筹资；仅经营不能叫完整余额核对。
勾稽：差异=独立实际期末-计算期末。独立余额缺失则明确未完成；非0保留，原因无证据不作断言。
证据：实际工作簿/区域/快照/工具回执与精确回查；未接通项目标阻塞。
下一步：缺失项、负责人、所需资料。所有结果统一交X检查。
