# v2指数溢出修订
原v1会将JSON数字1e999解析为float inf，若藏在未使用的额外字段且未提交回执哈希检查时，结果检查可错误通过。原版与v2同一输入对照已复现：v1 exit0，v2 exit1 JSON_NONFINITE。
v2自定义parse_float拒绝超范围非有限数；verify_result直接库API对完整result/context/receipt做规范JSON有限值校验，防绕过文件解析层。新增2个测试方法（含正负指数、有限普通数、CLI和三对象子例），72方法全绿。
新增两个有意删防线的变异都被测试抓到。v1历史15变异日志保留，不假称它们在v2重复执行。版本元数据、测试索引与最新输出已更新；共用业务接口/金额/状态闭集未变，仍未做平台或数据库实际验收。
