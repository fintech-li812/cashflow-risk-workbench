# 断连时怎么处理

1. 先运行只读doctor，另存新报告，区分文件/依赖错配和TCP不可达。
2. 有监听时只查监听PID和命令归属，不按旧PID杀进程、不重复启动。
3. 无监听且操作者已获原SSH访问授权时，可手动运行start_qa_tunnel.ps1 -KeyPath <本机授权密钥路径>；密码、私钥内容不放共享区。
4. 启动后先看新manual_runs目录的stderr与PID；失败记录原文，至少30秒再做有信息量排查，同问题最多3次。不反复点启动。
5. TCP恢复后用只读数据库事务核查QA表及既有固定请求，再用标准MCP只读检查。未查库不说数据库可用。
6. 仍失败保持阻塞，保留日志交X。不要开公网3306、改root授权或重建QA表来“修复”。
本卡不授权新服务器、新账户、生产写入、自动定时监控或千问界面接管。
