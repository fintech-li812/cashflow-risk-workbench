# 操作者如何登记资料

1. 业务方明确主体、账户与期间，提供独立余额凭证，不从算法输出反推余额。
2. 在自己的新目录准备四输入文件和来源记录。参考fixtures只是合成形状，不可把fixture主体或金额改名冒充真实。
3. 审批人核对原凭证、提取映射和纳入范围，在上传目录以外准备trust，登记四输入字节摘要与审批参考。程序不自动批准自己生成的trust。
4. 先在副本运行检查。blocked补实际缺件，invalid核对具体错误，不为过验收改摘要掩盖不一致。
5. 结果ready仍只有登记一致性，保存或计算前还要同范围完整收付数据及平台证据。敏感账户号不进共享包，使用内部account_id或脱敏别名。
