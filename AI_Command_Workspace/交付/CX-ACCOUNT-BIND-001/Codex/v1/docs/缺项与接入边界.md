# 真实资料缺项与后续接入

本轮仅完成工程，不拥有真实企业账户、开户行、范围批准、期初或独立期末原始凭证。样例表G列固定值不是独立实际余额，B9缓冲值也不是期初余额，均未拿来填缺。
由X/业务方提供：统计主体和纳入/排除账户清单、期间截止、来源提取记录及原凭证定位、独立性审批、明确单位与固定摘要。
真实文件可按合同由明确映射产生JSON；本模块不负责Excel解析或平台原生读取，这分别归外包01/03。
后续由协调方把ready绑定工件与同context的真实收付明细关联，才进入现金流计算完整性检查。本模块不改7个MCP工具、不自动清除workbench的未绑定提示，需经审查接入真实资料后再更新。
四外包包不被本模块替代：导入/报告/原生适配/发布总检仍各自交付。本模块也不替代平台认证、资金分类或真实业务最终验收。
