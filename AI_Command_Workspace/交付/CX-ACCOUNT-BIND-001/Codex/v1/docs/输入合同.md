# 账户与余额绑定输入合同 v1

本模块新增mfg-account-balance-binding.v1诊断工件，业务status和gate闭集保持原样。
入口check --bundle DIR --trust JSON --output-dir NEW [--allow-fixture]；输入四文件context.json/scope.json/balances.json/evidence_manifest.json。
五字段tenant_id/company_id/period/source_revision/run_id在全部工件和外部trust中精确一致；不是认证机制。

scope.schema_version=mfg-account-scope.v1；origin=offline_fixture或operator_registered_evidence；unit=CNY；scope_confirmed布尔；reporting_entity_id非空；opening_as_of为所选月份前一天，closing_as_of为当月最后一天。
accounts每项account_id/reporting_entity_id/currency/included。included必须布尔；排除需exclusion_reason；账户不重复，同范围主体明确，外币阻塞不换算；不接受明文account_number/iban。

balances.schema_version=mfg-balance-observations.v1；unit=CNY；records每项record_id/account_id/kind(opening或closing)/as_of/amount/unit/evidence_id/source_record_id。金额为元两位小数字符串，null表示缺失，不能用浮点或指数串。同账户同阶段只允许一项。
manifest.schema_version=mfg-balance-evidence-manifest.v1；sources每项evidence_id/path/sha256/source_class/independence/approval_ref。source_class仅bank_statement_extract或reconciled_ledger_extract；independence必须operator_approved_independent_actual，另有审批定位，不将此标签当作独立认证。
source.schema_version=mfg-balance-source-records.v1；source_class/origin/五字段匹配；derivation=registered_independent_actual。records每项source_record_id/account_id/kind/as_of/amount/unit/source_location；与余额逐字段相等。来源可以包含同账户两个阶段，不能拿计算现金流结果替代。

trust.schema_version=mfg-account-binding-trust.v1；industry=manufacturing；approval_ref非空；同五字段；approved_inputs四文件各自字节SHA256；allow_fixture显式布尔。trust在上传bundle外，不能由检查程序自行更新审批摘要。
路径相对、无..或绝对/ADS/符号链接跳转；单输入≤1MB、单来源≤2MB；最多1000账户/2000余额记录，读取前后内容须不变。金额整数最多18位，合计溢出明确阻断。
