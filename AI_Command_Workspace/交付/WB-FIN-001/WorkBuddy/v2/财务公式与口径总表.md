## 0 · 先说清楚三件事

### 0.1 一句话概括这套账怎么算

> **先把数据洗干净（数据闸）→ 算出企业每个月要花多少钱（M）和手上有多少钱能扛（B）→ 用「B ÷ M」这个倍数跟行业系数 K 比较出红黄绿灯 → 同时用三层模型（数据质量 Q / 财务健康 D / 舞弊概率 P）出一盏"模型灯" → 两盏灯取更严厉的那盏 → 按灯级和金额大小决定谁来签字 → 每月再跑四种压力场景看最坏情况。**

### F-01 · 月均经营性流出 M —— "这家企业平均一个月要花多少钱" 【已批准】

- **输入**：`现金流水!E`（经营性流出，万元），近 3 个完整月
- **单位**：万元｜**窗口**：近 3 个完整月
- **数学式**：`M = (E₁ + E₂ + E₃) / 3`
- **千问表格公式（待平台验证，v2 已补空值守卫）**：
  `=IF(COUNT(近3月经营性流出)<3,"待补录",AVERAGE(近3月经营性流出))`
  > **P1 修复说明**：v1 的公式列只有 `=AVERAGE(...)`，而表格语义是"空白不参与 COUNT、AVERAGE 自动忽略空白"，
  > 于是 `[90, 空白, 120]` 会算出 105 而不是报"待补录"——这正是"缺数据却算出结果"的假绿路径。
  > v2 用 `COUNT(...)<3` 强制守卫：不足 3 个数值即返回文本"待补录"，M 不出数。
- **空值/非数值**：缺失月**不得填 0**（会把 M 算成 66.6667）、**不得忽略后求均值**（会变成 100）→ 标"待补录"，M 不出数，下游全部标"不可判定"（不得补零报绿）
- **输出与边界**：M ∈ (0, +∞)；**M = 0 时缓冲倍数不适用**，不除零、不报绿
- **手算**：C01 `(90+100+110)/3 = 100.0000` ✅｜C02 缺失 → 待补录｜C03 M=0 → 倍数不适用
- **依据**：v8 行 638—639、1053；施工单 3.1 行 64；包B 行 41—49、A01 行 292—298、A05 行 321—326
- **平台依赖**：`AVERAGE`、`ISBLANK`/`ISNUMBER` 判定

### F-02 · 月均业务规模 S —— "这家企业一个月的生意盘子有多大"（审批分界的锚）【已批准】

- **输入**：近 3 个完整月（营业成本 + 管理费用），万元
- **数学式**：`S = AVERAGE(近3月(营业成本 + 管理费用))`
- **千问表格公式（待平台验证，v2 已补空值守卫）**：
  `=IF(COUNT(近3月(营业成本+管理费用))<3,"待补录",AVERAGE(近3月(营业成本+管理费用)))`

- **输出**：S ∈ (0, +∞)。**S 与 M 是两个不同字段，不能互相替代**（包B 行 41 明确）
- **手算**：C04 `[(80+20)×3]/3 = 100.0000` ✅（本例 S 恰等于 M，仅为便于手算）

### F-03 · 现金缓冲 B —— "真能拿来扛事的钱有多少" 【批准＋待确认】

- **通俗**：可动用的钱 = 已经验证到账的钱 + 账上现金余额 − 不管怎样都必须付出去的钱
- **输入**：已验证到账合计（应收账款 F/H + 银行流水 C/E）、`现金流水!G` 期末现金余额、刚性支出
- **单位**：万元｜**窗口**：当前快照
- **数学式**：`B = 已验证到账 + 现金余额 − 刚性支出`
- **千问表格公式（待平台验证，v2 已补空值守卫）**：
  `=IF(OR(COUNT(已验证到账金额区)<1,ISBLANK(期末现金余额),ISBLANK(刚性支出)),"不可判定",SUMIF(到账状态,"已验证",金额)+期末现金余额−刚性支出)`
  > **P1 修复说明**：v1 的公式列没有守卫，`SUMIF` 把空白当 0、`ISBLANK` 缺失时"减空白"等于"减 0"，
  > 结果是**刚性支出没填时 B 反而偏高**（虚高 → 可能把红灯算成绿灯）。v2 三项任一缺失即返回"不可判定"。
  > **落地提示**：`已验证到账合计`若为公式结果（非单元格引用），`ISBLANK` 不适用，改用 `COUNT(...)<1` 或 `ISNUMBER(...)` 判空——已在上方公式中按此写法给出；该差异待平台实测确认。
- **空值/非数值**：任一项缺失 → B 不出数 → 下游"不可判定"
- **输出与边界**：B 可为负（联合冲击场景会出现，直接判红）
- **依据**：演示看板 `renderCF` 卡片文案（html 行 883）；施工单 3.5 行 68（标注 ✅ 已解）
  > **P3-7 修正**：v1 此处还引了 v8 行 897，但那一行是"`有效缓冲 = SUMIF(已验证)`"，属 **F-04** 的公式，
  > 不是 B 的三项式。B 的权威依据只有施工单 3.5 行 68 与看板 html 行 883；v8 行 897 已归位到 F-04。
- **⚠ 两处未决**：① **"刚性支出"在任何文件里都没有定义**（来源表/字段/时间窗口全缺）→ **P-01**；② **已验证到账是否已含在"现金余额"里未声明**，若已含则是重复计入 → **P-09**
