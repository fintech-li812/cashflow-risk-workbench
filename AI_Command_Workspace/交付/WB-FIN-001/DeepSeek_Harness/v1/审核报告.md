## 4. P1：空值/缺值守卫只写在说明列，没有落到千问公式（假绿路径）

**位置**：`财务公式与口径总表.md` 的 F-01（`:77-78`）、F-02（`:90-91`）、F-03（`:105-106`）、F-11（`:207-210`）、F-13（`:229-232`）、F-18（`:305-308`）。

**问题**：这些条目的"空值/非数值处理"写得很清楚（缺失不得补 0、不得忽略、不得报绿），但同一行的"计划使用的千问表格公式"没有实现这些规则。表格的通用语义是：空白单元格参与比较时按 0、`AVERAGE` 忽略空白、`SUMPRODUCT` 把空白当 0、`PERCENTILE` 对不足 3 个样本仍返回值。逐条：

| 条目 | 公式列（原文） | 说明列要求 | 按公式列落地的实际行为 |
|---|---|---|---|
| F-01 | `=AVERAGE(近3月经营性流出)` | 缺失月不得忽略，M 不出数 | `[90, 空白, 120]` → 105；不报"待补录" |
| F-02 | `=AVERAGE(近3月(营业成本+管理费用))` | 同 F-01 | 同上 |
| F-03 | `=SUMIF(到账状态,"已验证",金额)+期末余额−刚性支出` | 任一项缺失 → B 不出数 | 刚性支出空白 → 减 0，B 虚高 |
| F-11 | `=PERCENTILE(FILTER(...),0.25)` | 同月样本 <3 → 强制回退静态 | 1 个样本也照算分位数，不回退 |
| F-13 | `=1-(SUMPRODUCT(Benford)+SUMPRODUCT(Myer))/(2*15)` | 缺项不出数 | 空白因子按 0 → Q 偏高，可能转绿 |
| F-18 | `=IF(OR(AND(D<0,P>=0.7),Q<0.3),"红灯",IF(OR(AND(D<0,P>=0.3,P<0.7),AND(Q<0.5,D<0),AND(D<0,P<0.3)),"黄灯",IF(AND(D>=0,Q>=0.5),"绿灯","不可判定")))` | Q/D 缺失 → 不可判定；P 未取得 → 不可判定（C42） | **D 空白**：`D<0` 假、`D>=0` 真 → Q≥0.5 时落**绿灯**；**P 空白且 D<0**：`P<0.3` 真 → 落**黄灯**，不是不可判定 |

**触发样本**：

- F-18：Q=0.8、D 空白、P=0.2 → 公式落"绿灯"；总表/脚本 C42 的规则是"不可判定"。
- F-18：Q=0.8、D=−0.2、P 空白 → 公式落"黄灯"；C42 要求"不可判定"。
- F-01：90、空白、120 → 公式落 105；说明列要求"待补录、M 不出数"。

**影响**：这是"缺数据 → 报绿/报黄"的路径，直接违反项目红线"缺分母不能补 0 计算或报绿"（总表 `:434`、施工单 `4.10:92`）。F-13 的空白因子还会把 Q 抬高，与 F-18 组合后放大假绿。

**为什么脚本没发现**：脚本 `f18_fuse` 用 Python `None` 显式判断（`:230-248`），C42 用 `None` 传入，所以 PASS/BLOCKED；但**公式列不是 Python**，两者语义不同。脚本没有测"空白单元格"的表格语义。

**说明**：千问的空白/空串语义未实测，这一点我标"待平台复核"，但"公式缺 `ISBLANK`/`COUNT` 守卫"是静态事实，不依赖平台函数是否支持。若作者主张"实现时会补守卫"，请把守卫写进公式列，或在该列明确标注"仅为示意，落地必须补 `ISBLANK`/`COUNT` 守卫"。

**修改方向**：

- F-01/F-02：`=IF(COUNT(范围)<3,"待补录",AVERAGE(范围))`；
- F-03：`=IF(OR(ISBLANK(到账),ISBLANK(余额),ISBLANK(刚性支出)),"不可判定",...)`；
- F-11：`=IF(COUNT(同期样本)<3, 静态K, PERCENTILE(...))`；
- F-13：`=IF(COUNT(因子范围)<指标数,"不可判定",...)`；
- F-18：`=IF(OR(ISBLANK(Q),ISBLANK(D)),"不可判定",IF(AND(D<0,ISBLANK(P)),"不可判定",...))`，并在 P 未取得时先短路；
- 每条补一个"空白/缺值"用例，与现有 C02/C38/C42 对齐。

**复验条件**：公式列含显式守卫；新增空白单元格用例（不是 `None`）的实际输出为"待补录/不可判定"；F-18 的 D 空白、P 空白两例不再出现绿/黄。
