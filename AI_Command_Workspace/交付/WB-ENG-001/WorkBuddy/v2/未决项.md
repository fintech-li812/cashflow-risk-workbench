# v2 新增/升级项

## U-08 建库前置（R-10 连带影响）— 部署阻塞

- 事实：v2 已**删除** `CREATE DATABASE IF NOT EXISTS`（原因：cf_admin 仅有 `cf_workbench.*` 库级权限、无全局 CREATE，首句会以 ERROR 1044 中止整个脚本）。
- 影响：首次部署前必须**由有建库权限的操作**先建库，否则 `USE cf_workbench` 会报 ERROR 1049 中止（这是有意设计：宁可硬失败，也不要静默在错误库上建表）。
- 建库要求：`CREATE DATABASE cf_workbench CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;`
- 已知限制（如实登记）：collation 不符时**无法用 SIGNAL 做硬失败**——`cf_admin` 无 `CREATE ROUTINE` 权限，建不了存储过程。目前 collation 检查仍是"预检 SELECT 输出 + 部署者手动 ALTER"，**不是硬失败**。表级已显式 `COLLATE=utf8mb4_0900_ai_ci`，故库默认 collation 错误不会污染表结构。
- 需裁决：是否给 cf_admin 临时授予全局 CREATE（或建库专用管理账号），以及是否接受"collation 检查非硬失败"这一限制。
