# 下游使用边界

本模块消费01导入器未来产生的显式规范事实，但不实现其列映射，不改源行或日期。当前fixture自己构造，不等待外包返回。
账户范围来自CX-ACCOUNT-BIND-001；选择前只依赖范围可用，不声称独立余额已核实；完整对账需另核该绑定的余额状态与来源。
selected_records是合并口径选择；内部转账两端仍必须进入单账户核对，不能简单丢弃。原输入与record_decisions共同构成可复算轨迹。
分类未确认、利息口径未知、跨期内转或多个主源都列待核，不擅自裁决。未来真实业务计算仍应在批准的千问公式链执行。
本包不连接数据库、不启动端口、不新增MCP工具、不改现有原生或发布外包任务。
