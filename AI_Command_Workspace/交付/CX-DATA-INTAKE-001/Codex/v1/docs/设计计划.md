# 资料补齐页面设计

对象是提交制造业账户及余额资料的非技术队友。唯一目标是形成可交业务确认的草稿，不展示推测现金流，不批准账户范围。

颜色：纸面蓝灰#F3F6FA、正文深蓝#153A55、操作蓝#326BD0、完成绿#236E66、次要灰#667684、提示暖黄#FFF4D8。
字体：Microsoft YaHei UI/PingFang SC系统中文，标题32px、分区20px、正文14～16px；不依赖外部字体。
布局：左侧主要填写区，右侧固定资料缺项清单；账户采用连续行式区块。移动端顺序排列，单列输入，不依赖宽表格。
特征：把账户的期初和期末并排，并把凭证选择紧贴金额；可用性来自填写顺序和缺项反馈，不堆概览卡或模型大数。
自检：不采用暖奶油+陶土配色，不做暗色霓虹，不使用报纸式密集分栏或相同圆角卡片墙；只保留分区必要边界。
内容：用“可交确认”“缺少凭证”“待确认草稿”，不展示内部gate、MCP、SHA或认证术语干扰业务操作。下载JSON保留技术字段。
