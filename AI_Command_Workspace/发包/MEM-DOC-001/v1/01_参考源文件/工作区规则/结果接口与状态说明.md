# 制造业Agent结果边界接口（候选，不是MCP工具清单）

接口版本mfg-agent-result.v1。agent_guard.py提供validate_result、render_result、unavailable三个本地函数；不计算模型、不连服务器、不读写表格，不替代千问表格核心公式。
可信context要求tenant_id/company_id/period/source_revision/run_id，由实际认证/绑定层生成，不能从用户表格任意取。payload里同名字段必须逐项匹配。
status闭集success/missing_inputs/formula_error/unavailable是本模块新接口状态，不是gate_结果、风险灯或数据库event_type；不得直接塞入旧接口。issues为非空原因列表（success时为空）。非success金额必须null，不能用零充数。
成功结果要求：制造业、元、full_cashflow、明确calculation_version和workbook_ref/sheet/range/snapshot_ref来源；金额为分精度十进制字符串（18整数位上限），净额/余额/差异勾稽正确。缺独立实际余额时actual_closing和difference都为null，回答明确未核对，不能说全链路通过。
生产origin只接受qwen_sheet；测试专用offline_fixture必须显式allow_fixture=True且展示合成标记。origin标签本身不是安全认证！WorkBuddy必须让运行适配器绑定真实来源，不能允许用户自填origin后就被当作真实千问证据。
partial cashflow暂不接本“完整余额结果”接口，仍须有单独经营部分视图/说明；不能为通过校验伪造full_cashflow。
source_revision/snapshot_ref必须指向实际取数/重算快照，不是随便填字符串。该守卫只检查格式与一致性，无法证明表格真实性、平台权限、数据完整性或版本已发布，均由平台适配器/独立验收验证。

完整可复现payload见fixtures/synthetic_success.json，内容全为合成。未绑定真实平台时返回unavailable(context)，不得默认注入合成结果。生产不可打开allow_fixture。
持久化回执由后续真实接口提供，必须与请求/企业/期间/run匹配。当前代码不实现保存工具，也不会声称已保存。原schema映射、幂等、回查、超时不确定状态由WorkBuddy下一包补齐并由DeepSeek审核。
