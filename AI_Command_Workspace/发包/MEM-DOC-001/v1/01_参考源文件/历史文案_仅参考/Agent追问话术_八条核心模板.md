# Agent 追问话术 · 八条核心模板

> 面向财务风险管控工作台的对话智能体。这 8 条是使用频率最高、对"推动闭环"最关键的核心追问场景。每条含【触发场景】【追问目标】【话术模板】，方括号【】为动态变量。

---

## 第 1 条 · 数据异常追问

- **触发场景**：上传/关账数据触发数据闸拦截（营收<0、缺月、超收串户、空值）。
- **追问目标**：定位错误、拿到修正值，阻断脏数据进入判定链。
- **话术模板**：
```
检测到【字段 / 月份】存在异常：【错误描述】。请确认三点：
(1) 是录入有误，还是业务真实发生？
(2) 正确值应为多少？
(3) 是否需要重新导入该表？
```

---

## 第 2 条 · 预警归因追问

- **触发场景**：风控闸触发黄灯或红灯。
- **追问目标**：快速锁定归因主因，排出处置优先级。
- **话术模板**：
```
【指标】已触发【黄/红】灯：当前【当前值】，阈值【阈值】。
请优先确认：主因是【归因主因】吗？除此之外，还有哪些因素在同步推高风险？
```

---

## 第 3 条 · 应对方案追问

- **触发场景**：责任人在跟进群内响应预警。
- **追问目标**：拿到可执行、可验证的处置方案。
- **话术模板**：
```
请在 48 小时内给出方案，须包含四项：具体动作、责任人、完成时间点、预期回收/节省金额。
方案将写入跟进任务，作为闭环验证的判定依据。
```

---

## 第 4 条 · 催收回款追问

- **触发场景**：应收账款逾期（如重点客户逾期 41 天）。
- **追问目标**：锁定回款时间与责任人，驱动催收动作。
- **话术模板**：
```
【客户】单据【单据编号】已逾期【N】天、金额【X】万元。
请确认：最新回款承诺时间、对接人、是否需要发催收函或升级？预计到账日期？
```

---

## 第 5 条 · 方案推演追问

- **触发场景**：用户问"如果回款再延一个月会怎样"。
- **追问目标**：量化情景冲击，给出推演结论与动作。
- **话术模板**：
```
按【情景】测算：现金缓冲将降至【X】天，触及【黄/红】灯，需触发【对应动作】。
是否要我把该情景加入压力测试，并同步推送管理层？
```

---

## 第 6 条 · 假设分析追问（敏感性）

- **触发场景**：用户追问"改善哪个指标最有效"。
- **追问目标**：定位关键驱动变量，给出最优杠杆。
- **话术模板**：
```
当前缓冲由【变量A】（贡献【X%】）、【变量B】（贡献【Y%】）驱动。
要把缓冲拉回红灯线以上，最有效杠杆是【变量A】。是否测算将其优化【幅度】后的效果？
```

---

## 第 7 条 · 审批 / 例外追问

- **触发场景**：分级审批或例外放行提交。
- **追问目标**：确认理由合规、依据充分、留痕完整。
- **话术模板**：
```
本笔【金额】属【审批层级】。请补充：事由与依据是什么？为何走例外？是否有替代方案？
信息将自动留痕，季度回溯纳入统计。
```

---

## 第 8 条 · 闭环确认追问

- **触发场景**：跟进任务临期或标记完成。
- **追问目标**：确保"真闭环、可验证"，而非仅点完成。
- **话术模板**：
```
任务即将到期，请确认是否已完成？
若已完成：缓冲是否已恢复至黄灯线以上（验收标准）？
若未完成：需申请延期并说明原因，否则将自动升级通知。
```

---

> 说明：8 条覆盖了数据质量→风险判定→处置→催收→推演→假设→审批→闭环的完整链路，可与《钉钉推送话术_六类》配套使用——表格层/钉钉侧执行动作，对话侧负责追问与确认。
