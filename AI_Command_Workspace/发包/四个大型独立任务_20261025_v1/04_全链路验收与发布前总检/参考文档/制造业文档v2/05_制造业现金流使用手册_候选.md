# 制造业现金流使用手册 v2

适用本期制造业实际现金流。先准备企业、期间、账户范围、期初余额、经营/投资/筹资明细及独立实际期末余额。未知项留空并登记，不填0。

## 当前能做什么

千问已接入7个MCP工具，可查项目状态、列制造业来源、只读检查样例及列缺项。
合成演示结果已完成千问Agent读取、保存、精确回查和同编号重复保存，独立SQL核验仅一条。
这不表示样例企业已有完整财务结论，也不表示原生表格重算已通过。
制造业样例仍被D8、重复行定性、完整映射与独立余额等缺项阻断，不能保存为真实完整结果。

## 日常使用

1. 在千问任务中使用mfg-workbench-integrated技能，先查状态，再列来源；来源标识采用工具实际返回值。
2. 只读检查制造业样例，确认源摘要、实际Sheet与区域，读取就绪诊断。D8不自动缩放，行12/15不删除，正常部分到账不当错误。
3. 原生表格需X在平台内创建或导入独立副本、留下工作簿标识，再分别验证公式自动重算与Agent原生读表。客户端里能算不等于Agent能读取。
4. 分类、账户、余额、单位及来源证据全部满足后才计算真实结果。当前缺项只列清单；合成演示快照不能补进真实来源。
5. 如获授权保存，核对回执与存储后端，再按同一request_id及完整身份版本精确回查；禁止用“最新一条”替代。
6. 保存超时先回查同一逻辑请求。需要重试时至少等30秒，仍用相同编号和payload；同问题最多3次，失败保留报错停止，不连续点击保存。
