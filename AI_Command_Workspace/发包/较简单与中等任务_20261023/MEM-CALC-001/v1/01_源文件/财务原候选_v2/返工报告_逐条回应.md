## 一、P1（唯一阻塞级）：空值守卫只写在说明列，没落到千问公式列

**审核问题**：F-01/F-02/F-03/F-11/F-13/F-18 的"空值处理"说明写得很清楚，但同一行的千问公式列没有实现这些规则；而表格语义是"空白当 0 / AVERAGE 忽略空白 / PERCENTILE 样本不足仍返回"。后果是**缺数据 → 报绿/报黄**。

**v2 修复：6 条公式列全部加显式守卫**

| 条目 | v1 公式列 | v2 公式列（加守卫） | 修掉的假路径 |
|---|---|---|---|
| F-01 | `=AVERAGE(近3月经营性流出)` | `=IF(COUNT(...)<3,"待补录",AVERAGE(...))` | `[90,空白,120]` 由 105 → **待补录** |
| F-02 | `=AVERAGE(近3月(营业成本+管理费用))` | `=IF(COUNT(...)<3,"待补录",AVERAGE(...))` | 缺月不再被静默忽略 |
| F-03 | `=SUMIF(...)+余额−刚性支出` | `=IF(OR(COUNT(...)<1,ISBLANK(余额),ISBLANK(刚性)),"不可判定",...)` | 刚性支出空白时 B 由**虚高 300** → **不可判定** |
| F-11 | `=PERCENTILE(FILTER(...),0.25)` | `=IF(COUNT(同期样本)<3, 静态K, PERCENTILE(...))` | 样本<3 不再算分位数，回退静态 |
| F-13 | `=1-(SUMPRODUCT(...)+SUMPRODUCT(...))/(2*15)` | `=IF(COUNT(...)+COUNT(...)<30,"不可判定",...)` | 空白因子不再当"未命中"，Q 不再被抬高 |
| F-18 | 无守卫的 IF 链 | **最外层先短路 `ISBLANK(Q)/ISBLANK(D)`，再短路"D<0 且 P 未取得"**，最后才走灯级分支 | D 空白由**绿灯** → 不可判定；P 空白由**黄灯** → 不可判定 |

**关键：脚本新增"表格空白单元格"语义建模（C56—C62，全部 PASS）**

v1 脚本用 Python `None` 显式判断，所以测不出表格语义——审核说得对。v2 引入 `BLANK` 哨兵，并写了**守卫版 vs v1 无守卫版**的对照函数，每条用例同时输出两者：

| 用例 | 输入 | 守卫版（v2） | v1 无守卫 | 结论 |
|---|---|---|---|---|
| C56 | 90 / 空白 / 120 | **待补录** | 105.0000 | 缺陷真实存在，已修 |
| C57 | 100 / 空白 / 100 | **待补录** | 100.0000 | 已修 |
| C58 | 到账 100、余额 200、刚性**空白** | **不可判定** | 300.00（虚高） | 已修 |
| C59 | Q=0.8、D**空白**、P=0.2 | **不可判定** | **绿灯** | 已修（最严重） |
| C60 | Q=0.8、D=−0.2、P**空白** | **不可判定** | **黄灯** | 已修 |
| C61 | 15 项因子中 1 项空白 | **不可判定** | 0.5333（Q 偏高） | 已修 |
| C62 | 同月样本 2 条 | 回退静态 Ky=2.5 | — | 已修 |

**复验条件达成**：公式列含显式守卫；新增"空白单元格"用例（不是 `None`）实际输出为"待补录/不可判定"；F-18 的 D 空白不再绿、P 空白不再黄。

**未做（如实）**：千问的空白/空串语义**未实测**。我标了"待平台复核"，并在公式下方写了落地提示：若 Q/D 由公式产出（非单元格引用），`ISBLANK` 不适用，需改用 `NOT(ISNUMBER(...))`——这个差异只能由平台实测确认。
